# GDG Campus Stall Quiz

A tiny, student-friendly tech quiz and club introduction for a campus GDG stall.

This project is intentionally small: a visitor can answer three beginner questions, get an instant score, and learn how to join a team. It runs in a browser with no build step, framework, or account.

## Project status

The one-page demo and its stall activity are being prepared in the [`build/gdg-campus-stall-quiz`](../../compare/main...build/gdg-campus-stall-quiz) pull request.
